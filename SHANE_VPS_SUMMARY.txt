9. SUPPORT & TROUBLESHOOTING
================================================================================

If Tests Fail:
  1. Verify MEMORI_DB_PATH exists and is writable
  2. Check GENESIS_MEMORY_BACKEND=memori is set
  3. Ensure data/memori/ directory exists
  4. Run: pip install -r requirements.txt

If Auto-Mirroring Not Working:
  1. Verify DREAMGYM_AUTO_MIRROR=true in .env
  2. Check infrastructure/dreamgym/ modules import
  3. Verify HAS_DREAMGYM flag is True
  4. Check logs for async errors

If Database Errors:
  1. Verify SQLite file has write permissions
  2. Check disk space available
  3. Ensure no file locks on database
  4. Try removing data/memori/genesis_memori.db and restarting
