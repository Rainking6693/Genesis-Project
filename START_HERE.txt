  TROUBLESHOOTING QUICK REFERENCE
================================================================================

Task won't start       → Check logs, verify Python path, test manually
Task fails (Result: 1) → See logs for error (last 50 lines)
Timeout error          → Reduce --population or increase timeout to 2 hours
Access denied          → Enable "Run with highest privileges" in task settings
Computer won't wake    → Enable "Wake computer to run task" in Conditions
No adapter updates     → Verify models/lora_adapters/current/ directory exists
